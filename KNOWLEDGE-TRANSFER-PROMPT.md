## Backend and business rules

- Explain the ASP.NET Core .NET 10 Minimal API and its four projects. API is the HTTP and composition layer, Application implements use cases and repository contracts, Domain owns business rules, and Infrastructure implements PostgreSQL persistence with EF Core/Npgsql and targeted SQL. Start with `backend/src/AppDeCaixa.Api/Program.cs`, the endpoint classes, and the xUnit architecture tests.
- Trace bootstrap, token issuance, and authorization. An existing company can use `POST /api/auth/bootstrap-manager`. An empty migrated database can use `POST /api/auth/bootstrap-company-manager` to create the company and first Manager transactionally. Explain `Bootstrap__AdminKey`, the `X-Admin-Bootstrap-Key` header, bootstrap rate limiting, and removing the key after provisioning. Explain password hashing, the 15-minute bearer JWT, company and actor claims, Manager-only user creation, and Employee-to-collaborator linkage. Cover Manager recovery as an open operational decision.
- Build a role and capability matrix for Manager, Cashier, and Employee. Include administrative creation of users, collaborators and services, cash operations, commission management and employee self-service. Trace company scoping from the JWT to queries, and the Employee collaborator scope from the signed-in account.
- Walk through opening the only active cash session for a company, creating a named comanda, adding services with a collaborator, capturing the catalog price and commission snapshot, making justified price adjustments, taking a full checkout payment, reconciling and closing the drawer. Describe how repeat checkout is guarded and where database transactions, row locks, and unique constraints enforce key invariants. Trace one representative request from UI to BFF to endpoint, use case, repository, and affected rows.
- Explain checkout methods Pix, Dinheiro, debit card, credit card, and Manager-authorized Fiado with a note. Fiado closes the order and records a debt. The API lists open debts and accepts partial or split settlements using one to four distinct supported methods, within the outstanding balance and with an open cash session. Receipts belong to the receiving drawer. Preserve the Fiado origin and show how the remaining debt is calculated.
- Explain reconciliation and commissions with concrete examples. Expected cash equals opening cash plus Dinheiro receipts plus CashIn minus CashOut. Pix and card amounts are reported separately, and Fiado originations contribute to outstanding debt. Closing difference equals counted minus expected cash. Default business timezone is `America/Bahia`. Amounts are whole BRL stored as integers. Commission periods are days 1–15 and 16–month end by local order closing date. Use the charged item value and saved percentage, round each line to whole reais with halves up, and include Fiado orders when they close. Show Manager previews and Pix/Dinheiro payouts, duplicate payout protection, and Employee read-only history.
